RELAY NODES
    Relays are servers that store and transmit Nostr events. Connect to multiple relays for better censorship resistance.
    🧅 TOR / ONION RELAYS
    Connect to .onion relays for maximum privacy. Your IP is hidden from relay operators and your ISP can't see which relays you use.

    Requirements:
    → Android: Install Orbot and enable VPN mode for this browser
    → Desktop: Use Tor Browser or configure a SOCKS5 proxy (127.0.0.1:9050)
    → Note: Onion relays use ws:// (not wss://) — this is normal and secure within Tor

    📡 LOCAL MESH / COLLAPSE MODE
    Offline transport for public signed Nostr notes. Glowstr still verifies every event ID and Schnorr signature before showing it. Private DMs, wallet data, and keys are never sent through this mesh mode.
    MESHTASTIC // BLUETOOTH → LoRa
    Connect directly to a nearby Meshtastic radio with Web Bluetooth. Signed notes are compressed when useful, split into small PRIVATE_APP packets, and reassembled by other Glowstr mesh users.
    DISCONNECTED
    Requires a browser with Web Bluetooth. Glowstr uses Meshtastic private app port 256, not the reserved Reticulum tunnel port.
    RETICULUM // LOCAL BRIDGE
    Connect Glowstr to a local Reticulum instance through the companion bridge. Reticulum can then move notes across RNode/LoRa, Wi‑Fi, Ethernet, packet radio, or other configured RNS interfaces.
    DISCONNECTED
    The token is session-only. The bridge binds to loopback by default and never receives your Nostr private key.
    🔵 BLUETOOTH DIRECT // PHONE ↔ PHONE
    Use the FOSS Glowstr Android helper for direct phone-to-phone BLE. The helper advertises and scans nearby Glowstr phones, uses secure LE L2CAP streams, verifies NIP-01 IDs + BIP-340 signatures, and stores valid public notes while the PWA is closed.
    HELPER DISCONNECTED
    NO PEERS
    Android helper endpoint: 127.0.0.1:8788. The token stays in session storage only. Chrome/Vanadium may ask for Local Network Access to reach the loopback helper.
    Use the MESH feed to see notes received through any mesh transport.

    Glowstr is a privacy-first Nostr client that helps you see through the noise. Built with a retro terminal aesthetic and an uncompromising commitment to user sovereignty. Nostr = Notes and Other Stuff Transmitted by Relays. A simple, open protocol for decentralized social networking. No accounts. No servers you don't choose. No censorship. Inspired by cypherpunk values and built as a lightweight PWA, Glowstr connects directly to relays via WebSocket and keeps your keys under your control — always. Current Features: → Amber signer (NIP-55 intents + NIP-46 bunker) → NIP-07 browser extension support → Private key login with inline Schnorr signing → Tor onion relay support with Orbot/Tor Browser → Real-time global feed via WebSocket → Publish notes (kind 1 events) → Multi-relay management with latency → Search notes by content → Installable PWA — works offline → Zero tracking. Zero analytics. Zero compromise.
